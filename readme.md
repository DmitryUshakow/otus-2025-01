Рекомендации по прохождению тестов
Для успешного прохождения всех тестов рекумендоуется указать в confingProjectHW.ts не зарегистрированную почту в demoshop
Первыми запускать проверки из файла hwAuth.spec.ts
Последними запускать тесты из файла hwAccount.spec.ts
Из-за теста создания нового пользователя, автотесты запущенные сразу на нескольких брузерах будут выдавать ошибку, успешным будет только тест в первом браузере. Для решения данной проблемы, понимая, что в первую очередь были создаными функциональные проверки, количество браузеров в настройках было сокращенно до 1 и выбран самый популярный Chrome
Рекомендуется тесты запускать в следующей последовательности
npx playwright test hwAuth.spec.ts
npx playwright test hwNavMenu.spec.ts
npx playwright test hwShoping.spec.ts
npx playwright test hwAccount.spec.ts
Единственное слабое месте это 2 теста user register success и creating registrated user again / либо пользователь уже создан и первый упадет, либо еще не создан, но второй раньше что ли отрабатывает или одновременно и второй тест падает, как будто пользователь еще не был создан / по отдельности эти тесты работают
Установил jest и npm install --save-dev jest-github-actions-reporter
